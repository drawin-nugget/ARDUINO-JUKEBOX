# ARDUINO-JUKEBOX
A code to play some 8bit songs and experiment a little with a buzzer, LCD screen and push buttons. 

This code is currently using the songs code made by Robson Couto, you can find more of his songs in this link.

https://github.com/robsoncouto/arduino-songs/blob/master/keyboardcat/keyboardcat.ino

I want to clarify that I am no expert and this code is still a WIP and definitely not perfect. I just you guys enjoy it, and learn something with it.
